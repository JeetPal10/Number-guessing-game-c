## Overview

This project is a console-based Number Guessing Game implemented in C. The application generates a random number within a specified range, and the user attempts to guess the correct value with guidance provided after each attempt.

The project was developed to strengthen core programming fundamentals including control flow, loops, random number generation, and user interaction.

---

## Features

- Random number generation
- User-friendly console interface
- High/Low guessing hints
- Attempt counter
- Simple and efficient implementation
